# CareerOS Roadmap

Roadmap data is defined in code at `packages/career-core/src/roadmap/index.ts` and rendered at `/roadmap` in the web dashboard.

## Phases

### Phase 1 — ApplyPilot MVP (current)

- User profile
- Resume storage
- Job extraction
- Autofill detection
- Autofill execution
- Unknown-field learning
- Save application
- Basic dashboard

### Phase 2 — Application Intelligence

- Application tracker
- Resume-to-job matching
- Cover letter generation
- Custom question answering
- Application analytics

### Phase 3 — Recruiter + Interview

- Recruiter CRM
- Follow-up reminders
- Interview prep
- Mock interview scaffolding
- Behavioral story bank

### Phase 4 — Career Intelligence

- Career analytics
- Skill gap analysis
- Job market insights
- Salary intelligence
- AI career coach

### Phase 5 — Full CareerOS

- Networking graph
- Portfolio builder
- Knowledge graph
- Automation engine
- Integrations
- Privacy controls
