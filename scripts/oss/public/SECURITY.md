# Security policy

CareerOS runs on your own machine and stores your resume, application history and browser
sign-ins locally. Both Docker ports are bound to `127.0.0.1`; do not expose them to the internet,
because the API has no login.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's **Report a vulnerability** button on the
repository's Security tab to send a private report, with steps to reproduce and the impact you
see. You should get a reply within a week. Please give us a reasonable time to fix the problem
before disclosing it.
